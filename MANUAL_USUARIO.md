# Manual de Usuario - AhorrApp

## Introducción

AhorrApp es una aplicación móvil diseñada para ayudarte a gestionar tus finanzas personales de manera eficiente y organizada. Este manual te guiará a través de todas las funcionalidades disponibles.

## Primeros Pasos

### 1. Registro e Inicio de Sesión

#### Crear una Nueva Cuenta
1. Abre la aplicación AhorrApp
2. En la pantalla de inicio, toca "Registrarse"
3. Completa los campos requeridos:
   - **Nombre de usuario**: Elige un nombre único
   - **Contraseña**: Crea una contraseña segura
   - **Confirmar contraseña**: Repite tu contraseña
4. Toca "Registrarse" para crear tu cuenta

#### Iniciar Sesión
1. En la pantalla de inicio, ingresa tu nombre de usuario
2. Ingresa tu contraseña
3. Toca "Iniciar Sesión"

### 2. Navegación Principal

La aplicación cuenta con una barra de navegación inferior con las siguientes secciones:

- **🏠 Dashboard**: Vista general de tus finanzas
- **💰 Transacciones**: Gestión de ingresos y gastos
- **📅 Calendario**: Vista de transacciones por fecha
- **📊 Resumen**: Estadísticas y reportes
- **⚙️ Configuración**: Ajustes de la aplicación

## Dashboard

### Vista General
El Dashboard es tu centro de control financiero. Aquí encontrarás:

- **Balance Actual**: Tu saldo total actual
- **Ingresos del Mes**: Total de ingresos en el mes actual
- **Gastos del Mes**: Total de gastos en el mes actual
- **Metas de Ahorro**: Progreso de tus metas activas
- **Límites de Categoría**: Estado de tus límites de gasto

### Acciones Rápidas
- **FAB (+)** : Agregar nueva transacción
- **Tarjetas de Metas**: Toca para ver detalles completos
- **Tarjetas de Límites**: Toca para gestionar límites

## Gestión de Transacciones

### Agregar una Nueva Transacción

1. **Desde el Dashboard**: Toca el botón flotante (+)
2. **Desde Transacciones**: Toca "Agregar Transacción"

#### Campos Requeridos:
- **Monto**: Cantidad de dinero (solo números)
- **Descripción**: Breve descripción de la transacción
- **Categoría**: Selecciona una categoría predefinida
- **Tipo**: 
  - **Ingreso**: Aumenta tu balance
  - **Gasto**: Disminuye tu balance
- **Fecha**: Fecha de la transacción (por defecto hoy)

#### Categorías Disponibles:
- **Ingresos**: Salario, Freelance, Inversión, Bonus
- **Gastos**: Comida, Transporte, Vivienda, Entretenimiento, Salud, Educación, Compras, Servicios, Otros

### Ver Transacciones

#### Lista de Transacciones
- Muestra todas tus transacciones ordenadas por fecha
- Cada transacción muestra: monto, descripción, categoría, fecha
- Colores: Verde para ingresos, Rojo para gastos

#### Filtros Disponibles:
- **Todas**: Muestra todas las transacciones
- **Ingresos**: Solo transacciones de ingreso
- **Gastos**: Solo transacciones de gasto

### Editar Transacciones
1. Mantén presionada una transacción
2. Selecciona "Editar"
3. Modifica los campos necesarios
4. Toca "Guardar"

### Eliminar Transacciones
1. Mantén presionada una transacción
2. Selecciona "Eliminar"
3. Confirma la eliminación

## Metas de Ahorro

### Crear una Nueva Meta

1. En el Dashboard, toca "Agregar Meta"
2. Completa los campos:
   - **Nombre**: Nombre descriptivo de tu meta
   - **Monto Objetivo**: Cantidad que quieres ahorrar
3. Toca "Crear Meta"

### Gestionar Metas

#### Ver Progreso
- **Barra de Progreso**: Muestra el porcentaje completado
- **Monto Actual**: Cuánto has ahorrado
- **Monto Restante**: Cuánto falta para completar

#### Agregar Dinero a una Meta
1. Toca el botón "Agregar Dinero" en la meta
2. Ingresa el monto a agregar
3. Toca "Confirmar"

**Nota**: Al agregar dinero a una meta, se crea automáticamente una transacción de gasto que reduce tu balance general.

#### Editar Meta
1. Toca el ícono de editar (lápiz)
2. Modifica el nombre o monto objetivo
3. Toca "Guardar"

#### Eliminar Meta
1. Toca el ícono de eliminar (basura)
2. Confirma la eliminación

## Pagos Programados

### Crear un Pago Programado

1. Ve a la sección "Pagos Programados"
2. Toca "Agregar Pago Programado"
3. Completa los campos:
   - **Título**: Nombre del pago
   - **Monto**: Cantidad a pagar
   - **Categoría**: Categoría del gasto
   - **Intervalo de Repetición**: 
     - Diario
     - Semanal
     - Mensual
     - Anual
   - **Fecha del Próximo Pago**: Cuándo se ejecutará

### Gestionar Pagos Programados

#### Ver Pagos Activos
- Lista de todos los pagos programados
- Muestra: título, monto, categoría, próxima fecha
- Estado activo/inactivo

#### Editar Pago
1. Toca el ícono de editar
2. Modifica los campos necesarios
3. Toca "Guardar"

#### Eliminar Pago
1. Toca el ícono de eliminar
2. Confirma la eliminación

### Funcionamiento Automático
- Los pagos se ejecutan automáticamente en la fecha programada
- Se crea una transacción automática
- Se programa la siguiente fecha según el intervalo
- Recibirás notificaciones cuando se ejecute un pago

## Límites de Categoría

### Crear un Límite de Gasto

1. En el Dashboard, toca "Agregar Límite"
2. Selecciona una categoría
3. Establece el monto límite
4. Toca "Crear Límite"

### Seguimiento de Límites

#### Barra de Progreso
- **Verde**: Dentro del límite
- **Amarillo**: Cerca del límite (80-100%)
- **Rojo**: Excedido el límite

#### Actualización Automática
- Los límites se actualizan automáticamente con cada transacción
- Solo se consideran transacciones de tipo "Gasto"
- El seguimiento es mensual

### Gestionar Límites

#### Editar Límite
1. Toca el ícono de editar
2. Modifica el monto límite
3. Toca "Guardar"

#### Eliminar Límite
1. Toca el ícono de eliminar
2. Confirma la eliminación

## Vista de Calendario

### Navegación
- **Flechas**: Cambiar mes
- **Día actual**: Resaltado en azul
- **Días con transacciones**: Marcados con un punto

### Ver Transacciones por Día
1. Toca cualquier día del calendario
2. Se mostrarán todas las transacciones de ese día
3. Puedes agregar, editar o eliminar transacciones

## Consejos de Uso

### Para Mejor Organización
1. **Categoriza Correctamente**: Usa las categorías apropiadas para cada transacción
2. **Revisa Regularmente**: Revisa tu dashboard diariamente
3. **Establece Metas Realistas**: Crea metas alcanzables
4. **Usa Límites**: Establece límites para controlar gastos
5. **Programa Pagos**: Automatiza pagos recurrentes

### Mejores Prácticas
- Registra todas las transacciones, incluso las pequeñas
- Revisa tus límites de categoría regularmente
- Actualiza tus metas de ahorro según tus objetivos
- Usa descripciones claras para identificar transacciones

## Solución de Problemas

### Problemas Comunes

#### No Puedo Iniciar Sesión
- Verifica que el nombre de usuario y contraseña sean correctos
- Asegúrate de que la cuenta existe

#### No Se Guardan las Transacciones
- Verifica que todos los campos estén completos
- Asegúrate de tener conexión a internet (si aplica)
- Reinicia la aplicación

#### Los Límites No Se Actualizan
- Verifica que las transacciones estén categorizadas como "Gasto"
- Espera unos segundos para la actualización automática
- Reinicia la aplicación

#### Los Pagos Programados No Se Ejecutan
- Verifica que el dispositivo no esté en modo de ahorro de batería
- Asegúrate de que las notificaciones estén habilitadas
- Revisa la configuración de alarmas del sistema

### Contacto de Soporte
Si experimentas problemas que no se resuelven con estas soluciones, contacta al soporte técnico con:
- Descripción detallada del problema
- Pasos para reproducir el error
- Información del dispositivo (modelo, versión de Android)
- Capturas de pantalla si es posible

## Glosario

- **Balance**: Saldo total de tu cuenta (ingresos - gastos)
- **Transacción**: Movimiento de dinero (ingreso o gasto)
- **Categoría**: Clasificación de transacciones (comida, transporte, etc.)
- **Meta de Ahorro**: Objetivo financiero con monto específico
- **Pago Programado**: Transacción automática recurrente
- **Límite de Categoría**: Restricción de gasto por categoría
- **Dashboard**: Pantalla principal con resumen financiero
